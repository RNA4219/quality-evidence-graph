# Quality Evidence Graph v0.3.0

QEG 0.3.0は、0.2系のfail-closedな品質証跡契約へReliability / Resilienceを追加するpre-1.0 minor releaseである。

## Highlights

- resilience test / execution evidence、Reliability policy、signal manifest、accounting / drill-downの公開型とstrict schema
- DQ-18〜DQ-21、BLK-REL-01〜04、risk / test scope付きwaiver
- latest evidence selection、全current real attemptのsafety評価、mock除外、nearest-rank percentile
- artifact / signalのpath containment、symlink escape、SHA-256、revision検証
- Lakda HATE/v1、Toxiproxy、shell、CIからcanonical evidenceを作るnormalizer
- `evidenced_by` provenanceが`testId`と矛盾または曖昧な場合のDQ-18 fail-closed判定
- 53 fixture、うちReliability / Resilience 22件、public source / packed type contract、Node 20 / 24 CI

## Compatibility

- package / CLI / external Action versionは`0.3.0`。
- graph wire contractは`qegVersion=0.2`を維持する。
- discriminatorなしのlegacy test / execution evidenceとReliability無効graphは引き続き受理する。
- Reliability有効時は完全Git SHA、SHA-256 policy hash、profile / policy identity一致、artifact verification reportを要求する。

## Install

```sh
npm install --save-dev @quality-harness/quality-evidence-graph@0.3.0
npx qeg --version
```

GitHub Actions:

```yaml
- uses: RNA4219/quality-evidence-graph/qeg-report-action@v0.3.0
  with:
    targets: .qeg
```
