# Quality Evidence Graph 0.4.1 パッケージ

0.4.1は未公開0.4.0の開発分と、2026-09-11までの包括的改修をまとめたtarball版。package・CLI・同梱Action・runtime metadataは0.4.1、graph wire契約は`qegVersion=0.2`、実行環境はNode.js 20以上。

## 同梱する改修

- raw producer → graph → placement → gate → recordの明示入力契約と、出力世代の検証・公開・復旧、consumer移行。
- CLIのpath/discovery/baseline/diff、未解決参照・配置coverage・実行資格・oracle・waiver・保管方式・承認の整合。
- 手動証拠不足の診断と記録、手動失敗・未完了の判定、実行結果の矛盾検出、実体に基づく復帰、未承認reviewの制限。

機能ごとの受入と非評価範囲は[受入台帳](../project/evidence-acceptance-status.md)に保持する。過去の証拠とfixture期待値は変更しない。0.4.1は版の同期とパッケージ化であり、0.4.0で受入済みの判定契約を継承する。

## インストール

成果物は`quality-harness-quality-evidence-graph-0.4.1.tgz`、`SHA256SUMS`、source commit・検証結果を記録した`package-manifest.json`。tarballのSHA-256を照合してからインストールする。

```powershell
Get-FileHash -Algorithm SHA256 .\quality-harness-quality-evidence-graph-0.4.1.tgz
Get-Content .\SHA256SUMS
npm install .\quality-harness-quality-evidence-graph-0.4.1.tgz
node .\node_modules\@quality-harness\quality-evidence-graph\dist\cli.js --version
node .\node_modules\@quality-harness\quality-evidence-graph\dist\cli.js schema-check
```

`--version`の期待値は`0.4.1`。`init --root <consumer>`はこの配布物のAction・schema・licenseをconsumerへコピーする。旧native入力は明示的なinputContractへ移行し、`migrate --dry-run`で設定と差分を確認する。

## パッケージ作成と検証

```sh
npm run build
npm run test:package
npm run test:release-lifecycle -- --out <artifact-dir>/lifecycle/evidence.json
npm pack --json --pack-destination <artifact-dir>
```

最終tarballを隔離consumerへインストールし、package/CLI/Action/runtime metadataの版、library import、schema、正常goと手動失敗のno_go、record、initを確認する。manifestにtarballのSHA-256・source commit・CI・各確認結果を記録する。

作成したtarballを`QEG_PACKAGE_TARBALL`環境変数へ指定して`npm run test:package`を実行すると、その成果物に対して既存の配布テスト全体を実行できる。未指定時は従来どおり一時tarballを作成して検証する。

`private: true`を維持し、npm registryへの公開は行わない。GitHub公開済みのAction tagはv0.3.1であり、このtarballに未作成のv0.4.1 tag参照を含めない。
